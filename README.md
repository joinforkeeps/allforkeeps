# For Keeps

For Keeps helps nonprofit teams understand their technology choices before a
renewal, migration, or new system makes the decision for them. We share practical
guides about Open Source tools, self-hosting, real operating costs, and the work
of keeping a system healthy.

The goal is not to hand every organization the same stack. It is to help each
team see what it depends on, who will maintain it, and how to leave with its data
intact.

## What we are building

- Public quickstarts that begin with sample data and explain the trade-offs.
- A welcoming community for nonprofit builders to share useful field notes.
- Scoped assessments and hands-on projects, with responsibilities and pricing
  agreed before paid work begins.
- The first Frappe Learning course, currently in development.

The site is live, but paid work is not open for purchase yet. We are preparing
more updates for holiday training. Follow the [community page](https://allforkeeps.com/community)
for the next dispatch.

## Tools behind the site

- **Astro** for the static website.
- **Tailwind CSS v4** for the visual system.
- **Markdown and MDX** for guides and field notes.
- **Supabase** for planned assessment intake and account-based community posting.
  The dedicated For Keeps project still needs its configuration and migrations
  before those services are available.
- **Frappe Learning** for the course in development.

## Local development

The project expects Node.js 22.12 or newer and pnpm 9 or newer.

```sh
pnpm install
pnpm run dev
pnpm run build
```
