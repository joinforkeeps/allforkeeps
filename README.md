# For Keeps

For Keeps helps nonprofits build lasting ownership of the technology behind
their work. We back open source tools, practical self-hosting, and clear costs over
forced subscriptions.

This repository contains the source for [allforkeeps.com](https://allforkeeps.com/).
Not a starter template. Our first course is in development; course delivery is handled separately.

## Stack

Astro, Tailwind CSS v4, and Markdown/MDX.

## Local development

Uses Node.js 22.12+ and pnpm 9+
