Core sanctuary pages for Home, Quickstarts, Pricing, Community Hub, Changelog, About, Assessment Intake, and 404

MDX-powered open-source guides with verified zero-subscription architectures

Built-in dark mode styled like a deep navy command deck with zero flash on load

## Why it started

True help for nonprofits should never depend on ten paid licenses or recurring renewal cycles. This first release establishes the foundation so small teams can stop renting their tools and start owning them forever.
